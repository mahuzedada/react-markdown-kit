# Getting started

```bash
npm install @react-markdown-kit/renderer
```

```tsx
import Markdown from '@react-markdown-kit/renderer'

export function Article({ content }: { content: string }) {
  return <Markdown>{content}</Markdown>
}
```

That's all you need to get started. There's no provider to wrap your app in and no stylesheet to import.

## What you get by default

You get CommonMark, parsed with micromark instead of regular expressions.

Raw HTML isn't executed and unsafe URL schemes are blocked. See [Security](/docs/security).

The output is plain semantic HTML without classes or inline styles, so your own CSS applies to it directly. See [Styling](/docs/styling).

The renderer entry doesn't have `"use client"`, so it works in server components and static rendering. See [Server rendering](/docs/server-rendering).

## Turn on GitHub Flavored Markdown

```tsx
import { GfmMarkdown } from '@react-markdown-kit/renderer/gfm'

<GfmMarkdown>{content}</GfmMarkdown>
```

## Use your own components

```tsx
<Markdown components={{ a: AppLink, img: AppImage, code: CodeBlock }}>
  {content}
</Markdown>
```

You can replace any element. The override gets the element's props plus its source node. See [Components](./renderer/components.mdx).

## Add editing

The editor is a separate package, and the renderer doesn't depend on it.

```bash
npm install @react-markdown-kit/editor
```

```tsx
'use client'

import { useState } from 'react'
import { MarkdownEditor } from '@react-markdown-kit/editor'

export function Notes() {
  const [value, setValue] = useState('# Notes\n\nStart writing.')
  return <MarkdownEditor value={value} onChange={setValue} />
}
```

<EditorExample

What you store is plain Markdown (there's no editor JSON format to keep around). See [Editor basics](./editor/basics.mdx).

## Personalize the same document

The variables plugin fills in typed values while the renderer parses the document.

```tsx
import { variables } from '@react-markdown-kit/variables'

<Markdown extensions={[variables({ data: { user: { name: 'Chatis' } } })]}>{'# Hello {{user.name}}'}</Markdown>
```

See [Variables](/docs/variables/basics).
