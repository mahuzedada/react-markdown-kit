comparisons, and reference pages. The pages themselves were still present.

document layout. The redesigned site and these fixes remain local; this audit
did not deploy or submit indexing requests.

- Restored the missing homepage links under Guides, Compare and migrate, and Reference.
- Added small sitewide Docs, Comparisons, and Migration footer links.
- Preserved established page titles and headings while keeping metadata accurate.
- Included the new Markdown content files when calculating sitemap modification dates.

  sitemap coverage, link reachability, self-canonicals, indexability, and document dates.

Validation passed:

RMK_SITES_BUILT=1 pnpm exec vitest run tests/seo-links.test.ts tests/seo-surface.test.ts tests/site-page-dates.test.ts

The build produced 48 pages, all 431 targeted tests passed, and the SEO report
reported zero problems. Chrome inspection confirmed that the restored articles
remain visible in the simple Markdown layout.

## After deployment

Recheck the production sitemap, redirects, and restored homepage links. Use
Google URL Inspection to check the sampled guide's new address and Bing URL
Inspection to check the homepage. The existing deployment workflow supports
IndexNow notifications; a notification or indexing request is not proof of
indexing. Follow the migration's indexing and search-performance reports before
drawing conclusions about rankings.

Google documents the importance of [crawlable internal links](https://developers.google.com/search/docs/crawling-indexing/links-crawlable)
and explains that [site moves are processed per URL](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes).
Bing distinguishes its index results from live crawl checks in its
[URL Inspection documentation](https://www.bing.com/webmasters/help/url-inspection-55a30305).
